Learned vs Random Agent

Objective

To compare trained RL behavior with random action selection.

---

What the Experiment Does

- One agent uses learned Q-values.
- Another agent behaves randomly.
- Both agents attempt to reach the same goal.

The experiment compares:

- efficiency,
- consistency,
- and task success.

---

Observations

- Learned agent reaches goal more consistently.
- Random agent behaves inefficiently.
- Learned policies improve performance.
- Rewards guide better future decisions.

---

Main Understanding

Learning agents outperform random behavior because rewards improve policy quality over time.
