Two Symbol Communication System

Objective

To understand how agents communicate using a very limited vocabulary.

Agents can only use:

- 0
- 1

to coordinate tasks.

---

What the Experiment Does

- Sender observes the goal.
- Sender sends either 0 or 1.
- Receiver interprets the symbol and acts.
- Rewards determine communication success.

Failed communication changes the message mapping.

---

Observations

- Initial communication may be unstable.
- Useful symbol mappings survive longer.
- Limited vocabulary forces efficient communication.
- Stable message meanings gradually emerge.

---

Main Understanding

Limited communication encourages agents to develop efficient symbolic protocols for coordination.
