# Multi Goal Bottleneck System

## Objective

To understand how communication bottlenecks create information loss when agents must communicate many states using very few symbols.

---

# What the Experiment Does

* Sender must communicate:

  * LEFT
  * RIGHT
  * UP
  * DOWN

using only:

* 0
* 1

Multiple goals now share the same symbol.

---

# Observations

* Communication becomes ambiguous.
* Receiver cannot perfectly identify all goals.
* Limited symbols reduce coordination accuracy.
* Bottlenecks force compressed communication.

---

# Main Understanding

Communication bottlenecks create information compression problems when available symbols are fewer than possible environment states.
