Limited Vocabulary Grid Environment

Objective

To understand how limited-symbol communication affects coordination inside an environment.

---

What the Experiment Does

- Sender observes target position.
- Sender communicates using only:
  - 0
  - 1
- Receiver moves inside grid environment using received message.
- Rewards depend on successful navigation.

---

Observations

- Communication directly affects movement.
- Limited vocabulary restricts information transfer.
- Efficient communication improves navigation accuracy.
- Poor communication causes coordination failure.

---

Main Understanding

Communication becomes valuable when limited symbols are used to improve coordination inside environments.
