# Compressed Navigation Environment

## Objective

To understand how limited communication affects navigation and coordination inside environments.

---

# What the Experiment Does

* Sender observes target position.
* Sender communicates using only:

  * 0
  * 1
* Receiver navigates using limited information.

Several target positions now share the same message.

---

# Observations

* Communication cannot fully describe exact targets.
* Information compression creates uncertainty.
* Limited bandwidth reduces navigation accuracy.
* Efficient communication becomes more important.

---

# Main Understanding

Communication bottlenecks force agents to compress information, which introduces ambiguity and coordination difficulty inside environments.
