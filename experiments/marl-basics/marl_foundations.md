# Introduction to Multi-Agent Reinforcement Learning (MARL)

## Objective

These experiments introduce the foundational intuition behind Multi-Agent Reinforcement Learning (MARL) and demonstrate how multiple agents interact, cooperate, coordinate, and exchange information inside shared environments.

Unlike single-agent Reinforcement Learning, MARL involves:

* multiple learning agents,
* shared environments,
* coordination dynamics,
* and interdependent decision making.

The purpose of these experiments is to build conceptual understanding before moving into advanced MARL environments and emergent communication systems.

---

# Cooperative Gridworld Intuition

## Core Idea

This experiment demonstrates how multiple agents may need to coordinate actions to achieve a shared objective.

Two agents move inside the same environment and must reach the goal together.

---

## Main Understanding

In cooperative Multi-Agent Reinforcement Learning:

* successful task completion often requires coordination,
* synchronization between agents becomes important,
* and shared goals encourage cooperative behavior.

Unlike single-agent systems, agents must now consider:

* the behavior of other agents,
* shared outcomes,
* and coordinated movement.

---

## Important Observations

* Both agents progress together toward the same objective.
* Shared rewards encourage teamwork.
* Multi-agent systems naturally introduce coordination challenges.

---

# Shared Reward System

## Core Idea

This experiment demonstrates how shared reward structures encourage cooperation between agents.

Both agents must perform the required task together in order to receive a positive reward.

---

## Main Understanding

In cooperative MARL:

* rewards are often shared across agents,
* encouraging collaborative behavior instead of selfish individual optimization.

Shared rewards align:

* team objectives,
* agent incentives,
* and coordinated decision making.

---

## Important Observations

* Cooperation increases success probability.
* One agent alone may not be sufficient for task completion.
* Shared rewards encourage teamwork and coordinated policies.

---

# Communication Intuition

## Core Idea

This experiment introduces the concept of information asymmetry between agents.

One agent possesses important information while another agent initially lacks it.

Communication improves coordination and task success.

---

## Main Understanding

Communication becomes useful when:

* information is distributed unevenly across agents,
* and coordination depends on information sharing.

This forms the foundational intuition behind:

* emergent communication,
* sender-receiver systems,
* and communication-based MARL research.

---

## Important Observations

* Agent B initially lacks critical information.
* Information exchange improves coordination.
* Communication increases successful task completion probability.

# Key Multi-Agent RL Concepts Introduced

## Cooperation

Agents working together toward shared objectives.

---

## Coordination

Agents aligning actions to improve overall performance.

---

## Shared Rewards

Multiple agents receiving common rewards for cooperative success.

---

## Decentralization

Different agents possessing different local observations or information.

---

## Communication Necessity

Communication naturally emerges when coordination depends on distributed information.

---

# Difference from Single-Agent Reinforcement Learning

Single-Agent RL:

* one agent learns independently,
* environment remains relatively stable.

Multi-Agent RL:

* multiple agents learn simultaneously,
* agents affect each other’s environment,
* coordination and interaction become important.

This creates:

* non-stationary environments,
* dynamic interactions,
* and increased learning complexity.

These experiments form the conceptual foundation required before studying:

Emergent communication begins when:
