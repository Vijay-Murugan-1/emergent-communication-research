# Two Symbol Communication Environment

## Objective

To understand how agents develop communication using a very limited vocabulary.

Agents can communicate only using two symbols:
0 and 1.

## What the experiment does

A sender agent observes a goal.

The sender sends a symbol.

The receiver interprets the symbol and selects an action.

The reward determines whether communication was successful.

Successful communication strengthens the symbol meaning.

## Agents

### Sender Agent
Observes the goal and selects a communication symbol.

### Receiver Agent
Receives the symbol and performs an action.

## Actions

The receiver can choose:

- Left
- Right

## Observation

Initially, communication is random.

Over repeated interactions, useful symbol mappings become more stable.

## Main understanding

Limited vocabulary encourages agents to develop efficient symbolic communication protocols.
